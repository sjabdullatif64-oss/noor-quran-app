# 2. PURPOSE OF THIS COURSE

This course is **NOT** the existing Quran word-reading progression.

It is a foundation course that teaches the user how to recognize Arabic
letters and gradually read Quranic Arabic.

The learning path should progress from very basic concepts to simple
Quranic reading.

### Suggested progression

## LEVEL 1 --- Arabic Letters

Teach the individual Arabic letters from the beginning.

Examples:

**ا ب ت ث ج ح خ**\
**د ذ ر ز س ش**\
**ص ض ط ظ ع غ**\
**ف ق ك ل م ن**\
**و ه ء ي**

Each letter should be introduced individually.

For every letter:

-   Show the letter clearly.
-   Show its name.
-   Provide correct pronunciation/audio.
-   Let the learner listen.
-   Let the learner repeat/practice.
-   Give a simple recognition exercise.

Do not overwhelm the user by showing too many new letters at once.

------------------------------------------------------------------------

# 3. LETTER RECOGNITION PRACTICE

After introducing letters, give simple exercises such as:

**"Which letter is ب?"**

Show several choices.

Or:

**"Tap the letter you hear."**

The user should gradually learn to recognize letters visually and by
sound.

------------------------------------------------------------------------

# 4. LETTER SHAPES / CONNECTING LETTERS

After basic letter recognition, teach how Arabic letters appear in
different positions where applicable:

-   beginning
-   middle
-   end
-   isolated

Explain that Arabic letters can change shape when connected.

Use very simple examples.

Do not introduce complicated Quranic words too early.

------------------------------------------------------------------------

# 5. HARAKAT / SHORT VOWELS

After the user understands the letters, introduce:

-   Fatha **ـَ**
-   Kasra **ـِ**
-   Damma **ـُ**

Teach simple combinations such as:

**بَ**\
**بِ**\
**بُ**

Then:

**تَ**\
**تِ**\
**تُ**

Then gradually combine different letters.

The user should learn how the harakah changes the sound.

------------------------------------------------------------------------

# 6. TANWEEN

Introduce:

-   **ـً**
-   **ـٍ**
-   **ـٌ**

Explain and practice the sounds gradually.

Use simple examples and listening practice.

------------------------------------------------------------------------

# 7. SUKOON

Introduce Sukoon:

**ـْ**

Teach the user how a letter with sukoon is read.

Use simple combinations and gradually increase difficulty.

------------------------------------------------------------------------

# 8. SHADDAH

Introduce Shaddah:

**ـّ**

Explain that the letter is emphasized/doubled in pronunciation.

Provide listening and repetition exercises.

------------------------------------------------------------------------

# 9. MADD / LONG VOWELS

Teach basic long-vowel patterns using:

-   **ا**
-   **و**
-   **ي**

Examples should be introduced gradually.

The purpose is to teach the learner how to distinguish short and long
sounds.

------------------------------------------------------------------------

# 10. COMBINING SOUNDS

Once the learner understands letters and basic marks, start combining
them into simple readable units.

For example:

**بَ + تَ**

Then gradually move toward short Arabic/Quranic reading patterns.

Do not suddenly jump to long Quranic verses.

------------------------------------------------------------------------

# 11. SIMPLE WORD READING

After the learner understands the previous concepts, introduce very
simple Arabic/Quranic words.

Start with short and easy words.

Gradually increase complexity.

The learner should read the word themselves rather than simply
memorizing it.

------------------------------------------------------------------------

# 12. QURANIC READING TRANSITION

After completing the foundation stages, introduce short Quranic words
and then short Quranic phrases.

Eventually guide the learner toward reading actual Quranic verses.

This should feel like a natural transition:

**Letters**\
→ **Harakat**\
→ **Sounds**\
→ **Connected letters**\
→ **Simple words**\
→ **Quranic words**\
→ **Short phrases**\
→ **Quranic reading**

------------------------------------------------------------------------

# 13. LESSON STRUCTURE

Each lesson should be short and focused.

Suggested structure:

1.  Learn
2.  Listen
3.  Repeat
4.  Practice
5.  Quick Check
6.  Complete Lesson

Do not make lessons unnecessarily long.

The learner should clearly understand what they learned before moving
forward.

------------------------------------------------------------------------

# 14. AUDIO / PRONUNCIATION

Audio is very important for this beginner course.

For each new letter/sound:

-   Provide a clear pronunciation.
-   Allow replay.
-   Provide a dedicated listen button.
-   Let the learner repeat the sound.

The system should not assume that the learner already knows Arabic
pronunciation.

### IMPORTANT

Use the appropriate pronunciation/audio source for Arabic letters and
